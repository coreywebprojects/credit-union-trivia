Career fair prize quiz — kiosk spec

Portrait floor kiosk, 65″, rendering at 1080 × 1920 CSS px at 2× density. One random question from a pool of twelve, four answers, one prize. Every screen below is the live Kiosk Screen component at 32% scale — open Kiosk Quiz for the tappable flow.

1080 × 1920 · 9:16 60 px edge margin · 960 px content Touch only · no hover Fades · scale · position only

Screens

01 · Attract

Brand gradient field, type-led. Logo and 149 px headline sit at 108–652 px so they clear a crowd. Pulsing navy CTA at 1200–1400 px, 900 px wide so the 1.03 scale peak still clears the 60 px edge margin; whole screen is the tap target.

02 · Question — shortest

Q1 “What is the role of a Loans Officer at Sunrise Credit Union?” — one line of 56 px. Four 960 × 140 answers with 24 px gaps fill 880–1512 px, inside the interaction zone.

03 · Question — longest text

Q9 summer students — the longest question in the pool wraps to two lines and still ends well above 850 px. Answer text wraps to two lines inside the 140 px button.

04 · Question — longest answer

Q12’s 99-character answer is the wrapping worst case: two lines at 40 px fit the fixed 140 px height. Anything longer than this needs a copy edit, not a smaller type size.

05 · Answer pressed

Held for 700 ms before the result. The tapped answer inverts to navy and scales to 0.985; the other three go to the disabled treatment so the choice is unmistakable.

06 · Winner

Gradient field plus 184 px “You win!” — the only gradient screen with a headline this size, so staff can read the win from 3 m. Check badge, answer card, then Done.

07 · Not quite

Cream field, no gradient and no celebration — legible as “not a win” at distance without reading a word. X on the visitor’s pick, check on the answer, outline Done.

08 · Zone overlay

Reach zones mapped to height off the floor. Top 0–850 px (130–195 cm) is display only; 850–1750 px (65–130 cm) holds every touch target; 1750–1920 px stays empty.

Answer button — states

960 × 140 px, 4 px border, 24 px radius, 76 px letter badge, 40 px label. Shown at 50%. Correct and incorrect states are specified for a future inline-reveal variant; today the result is a full screen.

Right and wrong never rest on colour alone: a check or X glyph, a different word, a different background field, and a different button style all carry the same signal. Contrast: navy on cream 11.4:1, navy on gradient gold 8.1:1, navy on Ignite Orange 5.0:1, white on navy 12.6:1 — all AA or better.

New · motion

Transform and opacity only — nothing that forces layout or paint on Android 9. No blur, no box-shadow animation, no filters. All easing is the system’s --ease-out.

New components

KioskScreen

1080 × 1920 shell with the three reach zones. Props: screen, qIndex, pressed, chosen, showGrid + three callbacks. Fully presentational; the host owns timers.

AnswerButton

Letter badge + wrapping label. state: default · pressed · correct · incorrect · disabled. Fixed 160px height so the stack never reflows between questions.

TouchButton

140–200px pill. variant: navy · outline · gradient. Extends the system Button with kiosk heights and press-only feedback; hover styles removed.

ResultBadge

92px pill with a Lucide check or X at stroke-width 4 plus a 40px word. Filled white on the win field, white with a 4px error-red border on the not-quite field.

AnswerCard

White card: 28px eyebrow, 44–48px answer, 36px explanation. Gets a 16px green left rule on the not-quite screen where the answer needs extra emphasis.

ConfettiLayer

Confetti: 12 absolutely positioned rects and circles in navy, white and cream on one kioskFall keyframe.

Build notes

  • Answer order is shuffled per question index, so the correct answer is not always A. The pool ships with the correct answer first; the shuffle table lives in the component.
  • Logos in the design system are transparent PNG only — request or trace SVG masters before build. The full-colour logo is used on every kiosk screen, gradient and white alike; the white reverse is available for navy fields.
  • Icons are Lucide check and x via the system Icon wrapper, which fetches from a CDN. Bundle them locally — a booth on conference wifi cannot depend on a CDN.
  • Timings: 700ms pressed hold before the result, 60s auto-reset on a result screen if nobody taps Done.
  • Whole-screen tap on attract, single taps only everywhere else. Set touch-action: manipulation and -webkit-tap-highlight-color: transparent, and disable text selection and pull-to-refresh in the kiosk browser.
  • Ship a kiosk reset on page visibility change so a backgrounded browser always returns to attract.
